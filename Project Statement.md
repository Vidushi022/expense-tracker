# Student Expense Tracker

## Problem Statement
Students make a lot of small payments every day for
things like food, travel, sta7onery, books, snacks and
shopping. It is diﬃcult to keep track of all of them by
remembering or wri7ng in a notebook. Because of this,
many students do not know how much they spent in a
month or whether they are staying inside the budget they
planned.

The Student Expense Tracker is a simple Python project
that helps to record, organize, search and check these
expenses in one place.


## Scope

This project is only for personal expense management.
With it, a user can add, view, search, filter and delete
expenses. It can also find the highest expense, calculate
the spending of the current month, set a monthly budget,
show budget warnings and generate a simple expense
report.

The data is stored on the user's own computer in a
JSON file, so no online database or internet is needed.


## Target Users

- College students

- School students

- Students living in hostels


- Anyone who wants a simple record of their personal
expenses

## High-Level Features
1. Add and save expenses.
2. Keep expenses in categories.
3. Search and filter expenses.
4. Delete selected expenses.
5. Calculate the monthly spending.
6. Set and check a monthly budget.
7. Show budget warnings.
8. Find the highest expense.
9. Generate an expense report.
10. Save and load the expense data using JSON.

## Technical Approach
The project is divided into separate Python files so that
each file has its own work:
- main.py starts the applica7on.
- gui.py makes the Tkinter window.
- expense_manager.py handles the expense
opera7ons.
- budget.py does the budget checking and status.
- reports.py makes the reports and totals .
- storage.py saves and loads JSON file.

In this project I used the Python basics we learned so far:
variables, data types, conditions, loops, functions, classes,

GUI programming.
